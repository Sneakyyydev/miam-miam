MIAM-MIAM - sans compte dans l'appli, sans Firebase, gratuit, sans badge

Les données restent sur vos appareils (téléphone, PC). Les deux appareils se synchronisent
directement entre eux. Aucune clé, aucune configuration à coller.

1) METTRE L'APPLI EN LIGNE (une seule fois, gratuit : GitHub Pages)
 - Créez un compte gratuit sur github.com (il ne sert qu'à héberger les fichiers, pas à l'appli).
 - "New repository" > nom : miam-miam > Public > Create.
 - "uploading an existing file" > glissez TOUS les fichiers du dossier (pas le zip) > Commit changes.
 - Settings > Pages > Source : "Deploy from a branch" > main / (root) > Save.
 - Après ~1 minute : https://VOTRE-PSEUDO.github.io/miam-miam/

2) INSTALLER
 - Android (Chrome) : menu ⋮ > Installer l'application.
 - Windows (Chrome/Edge) : icône Installer dans la barre d'adresse.

3) RELIER VOS DEUX APPAREILS (une seule fois)
 - Réglages > "Mon code" > Copier (sur le téléphone).
 - Sur le PC : Réglages > coller le code > Associer.
 - Ensuite, dès que les deux appli sont ouvertes en même temps avec internet, tout se synchronise.
   Les modifications faites séparément sont fusionnées à la reconnexion.

4) SI LA SYNCHRO DIRECTE NE MARCHE PAS (réseau mobile strict, etc.)
 - Réglages > Exporter / envoyer : envoyez le fichier à l'autre personne (WhatsApp, mail...).
 - Elle fait Réglages > Importer : les deux versions sont fusionnées.

5) SAUVEGARDE : exportez de temps en temps, car les données ne sont que sur vos appareils.
   Reprise des anciennes données : Importer le fichier exporté depuis l'ancienne version.

MISE À JOUR : remplacer les fichiers dans le dépôt GitHub (Add file > Upload files).
